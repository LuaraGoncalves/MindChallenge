# Visual assets

These two illustrations were created for this interface with the built-in image generation tool. They are background materials; live text and controls are rendered in HTML.

## quest-board.png

Use case: stylized-concept. Asset type: full-bleed background for a cozy fantasy puzzle game web interface. Create a high-quality hand-painted 2D game environment, straight top-down view of a wide aged dark walnut wooden notice board / tabletop, horizontal planks and carved wooden frame edges. Landscape 3:2 composition. The central 75 percent is clean wood with subtle grain, medium dark but clearly readable. Only along the outer corners: a small cluster of green ivy top left, a brass compass and crimson wax seal near upper right, small teal cloth ribbon peeking from lower left and a wooden puzzle tile lower right. Painterly gouache, warm illustrated board-game art, slightly irregular handcrafted edges, not photorealistic. Palette espresso wood, honey highlights, deep teal, muted crimson and moss green. Flat frontal lighting, clear material texture. This will sit beneath live parchment HTML notes, so NO papers, NO interface, NO lettering, NO text, NO logos, NO watermark, NO UI controls, NO glows or particles.

## parchment.png

Use case: stylized-concept. Asset type: parchment paper texture for a hand-painted fantasy board game interface. One single flat rectangular landscape parchment sheet, straight top down, ratio 3:2, soft warm ivory paper with subtly mottled fibers, softly uneven worn edges, tiny organic nicks, slightly darker toasted edges. Entire center is clean empty light ivory suitable for dark small text. Hand-painted gouache texture, charming cozy adventure boardgame inventory UI. No scroll rolls, no objects, no pins, no lettering, no text, no symbols, no frame, no border drawings, no dramatic burn stains, no shadows outside sheet. Sheet almost fills image with very small transparent margin on all four sides. Native transparent background outside sheet.
